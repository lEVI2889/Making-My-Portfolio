## 📌 Overview

This repository documents the continuous, step-by-step engineering of a high-performance developer portfolio showcasing research publications, machine learning projects, and full-stack software systems.

### Key Architecture & Features
- **Obsidian Terminal Interface**: Interactive command parser supporting `help`, `bio`, `skills`, `projects`, and `contact` commands with terminal history navigation and blinking caret.
- **Git-Commit Timeline Tree**: Visual commit-node graph illustrating academic milestones, research roles, and engineering experience.
- **Filterable Technical Projects Grid**: Dynamic project cards filtered by domain (Machine Learning, Full-Stack, System Architecture).
- **Interactive Contact Dispatch**: Real-time form validation and simulated telemetry dispatch system.
- **Pure Vanilla Stack**: Zero bloated heavy frameworks, zero runtime dependencies — ultra-fast first contentful paint and responsive mobile design.

---

## 🛠️ Tech Stack
- **Structure**: Semantic HTML5 (Custom data attributes, ARIA accessibility)
- **Styling**: Modern CSS3 (CSS Grid, Flexbox, Custom Properties / Design Tokens)
- **Scripting**: Vanilla JavaScript (ES6+ Modules, Decoupled Schema Model)
